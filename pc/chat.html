🔑 AI 대화 켜기

우땅이가 AI(Claude)로 대답하려면 Anthropic API 키가 필요해요.

  1. console.anthropic.com 에 가입하고 결제 수단을 등록해요.
  2. API Keys 메뉴에서 키를 만들어요 (sk-ant- 로 시작).
  3. 아래 칸에 붙여 넣고 저장해요.

· 키는 이 PC에만 저장되고 다른 곳으로 보내지 않아요 (대화할 때 Anthropic에만 써요).
· 대화할 때마다 내 API 계정에 사용 요금이 조금씩 나가요.
· 내가 쓴 말과 우땅이 상태(이름·레벨·기분)가 Anthropic으로 보내져요. 비밀번호 같은 개인 정보는 적지 마세요.
· 키가 없어도 우땅이는 지금처럼 정해진 대사로 잘 놀아요.
